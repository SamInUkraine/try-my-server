# Як задеплоїти демо в облако (Render.com)

GitHub Pages НЕ підходить: він показує лише статичні файли й не вміє
запускати Python. Нам потрібен хостинг, що тримає сервер запущеним.
Безкоштовний і найпростіший — Render.com.

Після деплою отримаєш звичайне посилання `https://...`, і телефони
зможуть заходити навіть з мобільного інтернету. Wi-Fi в аудиторії
більше не впливає.

## Крок 1. Залий файли демо в репозиторій
У папці проекту мають бути: `server.py`, `requirements.txt`,
`templates/phone.html`, `templates/panel.html`. Закоміть і запушь
(у свою гілку або в main — з якої гілки захочеш деплоїти).

## Крок 2. Створи сервіс на Render
1. Зайди на https://render.com → **Sign in with GitHub** (увійти через GitHub).
2. Натисни **New +** → **Web Service**.
3. Під'єднай свій репозиторій (Render попросить доступ — дай, навіть до
   приватного репо це безпечно).
4. Налаштування:
   - **Branch** — гілка, де лежить демо.
   - **Language** — Python 3.
   - **Build Command** — `pip install -r requirements.txt`
   - **Start Command** — `python server.py`
   - **Instance Type** — **Free**.
5. Натисни **Create Web Service** і зачекай 2–4 хвилини, поки збереться.

## Крок 3. Отримай посилання
Угорі зʼявиться адреса виду `https://privacy-demo.onrender.com`.
- Сторінка для телефонів (для QR): це **корінь**, тобто просто
  `https://privacy-demo.onrender.com/`
- Панель для проектора: `https://privacy-demo.onrender.com/panel`

## Крок 4. QR-код
Зроби QR саме на адресу для телефонів (корінь, без `/panel`).
Будь-який генератор QR підійде, або попроси мене — зроблю картинку,
щойно даси посилання.

## Важливо знати
- **Безкоштовний Render «засинає» після 15 хв без відвідувань.** Перший
  захід його будить ~30–60 секунд. Тому відкрий посилання за 2 хвилини
  до виступу, щоб сервер уже прокинувся.
- WebSocket на Render працює — перевірено, усе реальний час.
- Нічого не зберігається: дані лише в памʼяті сервера, жодної бази даних.
  Перезапуск — усе чисто.

## Запасний варіант без деплою
Якщо з Render щось піде не так — можна лишити сервер на ноутбуці, а
телефонам дати публічне посилання через тунель `ngrok` (дає тимчасову
https-адресу). Про це скажи — розпишу окремо.
